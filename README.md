# 《万贯之后》
《万贯之后》是一款正在开发中的轻量化叙事模拟游戏。
玩家扮演一名普通出身的年轻商人，并得知自己十六年后必将成为天下首富。
游戏关注的并不是“能否发财”，而是玩家将如何抵达这个必然的终点，以及在财富增长过程中会得到和失去什么。
