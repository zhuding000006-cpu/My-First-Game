# 《万贯之后》游戏概念设计

> 版本：v0.1  
> 状态：初步策划

## 1. 核心设定
玩家扮演一名出身普通的年轻商人。
游戏开场，一位神秘人物告诉玩家：
“十六年后，你会成为天下首富。”
这不是预言，也不是概率事件，而是一个必然会发生的未来。
因此游戏的悬念不是“玩家能不能发财”，而是：
玩家会以怎样的方式走到那个注定的终点，又会在途中失去什么。
玩家可能经历投资失误、商号危机、疾病、背叛、权贵交易、亲友疏远等事件。错误通常不会立即导致游戏结束，而是迫使玩家用财富、健康、人情、声望甚至重要关系去弥补。
十六年后，玩家一定会成为天下首富，但最终的人生状态会根据一路上的选择发生巨大差异。
## 2. 故事梗概
故事发生在一个架空的古代东方王朝。
主角年轻时家境普通，手中只有少量本金，在一次偶然事件中得知自己十六年后必将成为天下首富。
玩家从经营一家小商铺开始，在十六年中经历不同阶段：
前期：生存与起步
玩家需要选择经营方向，在粮食、茶叶、丝绸、药材等商品之间进行买卖，同时认识最初的朋友、合伙人和家人角色。
中期：扩张与风险
随着财富增加，玩家开始接触更大的商路、产业以及权贵。时代事件会改变商品价格和商业环境，玩家可能遭遇战争、灾荒、政策变化、商业竞争和背叛。
后期：财富与代价
主角逐渐接近“天下首富”的位置，但过去的选择开始集中产生后果。
曾经帮助过的人可能成为关键助力；曾经背叛的人可能重新出现；过度劳累可能造成健康问题；依赖权贵可能换来巨大财富，却失去自由或声望。
最终第十六年，预言实现。
玩家站在自己拥有的一切面前，看到的不只是财富数字，还包括：
身体状况
亲友关系
社会声望
曾经做出的重要选择
最终人生评价
游戏最后提出：
“万贯之后，还剩什么？”
## 3. 主角与重要角色
主角
出身普通的年轻商人，姓名可由玩家决定。
初始特点：
资金有限
没有显赫背景
有一定商业能力
对未来充满野心
玩家通过选择逐渐塑造他的性格和人生。
神秘预言者
在游戏开头告诉主角：
“十六年后，你会成为天下首富。”
身份暂时不完全解释，可以作为贯穿游戏的悬念。
故交 / 合伙人
早期与主角共同创业的人。可能成为：
一生挚友
商业伙伴
竞争对手
被主角牺牲的人
家人
代表主角商业成功之外的生活，与玩家的时间分配、财富选择和重要事件相关。
权贵
中后期出现，可以给玩家提供极大的商业机会，但通常伴随高昂的隐性代价。
## 4. 场景设定
视觉方向暂定为：架空东方古代 + 2D插画 + UI界面。
主要场景包括：
初期的小商铺
城中集市
酒楼 / 商会
商路地图
大型宅邸
官府或权贵府邸
最终的首富府邸
画面不追求角色实时移动和复杂动作，更强调：
场景插画
人物立绘
商品图标
价格走势图
事件界面
数值和选择反馈
整体氛围希望从前期的热闹、希望感，逐渐转向中后期的繁华、压力和孤独感。
